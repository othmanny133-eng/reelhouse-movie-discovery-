# AI Assistance Declaration — Milestone 1

**Project:** REELHOUSE — Movie Discovery  
**Course:** Web Applications Programming and Engineering  
**Tool:** ChatGPT (OpenAI)

## Purpose of assistance

ChatGPT was used to assist with planning the React single-page application, drafting component code and client-side behavior, shaping the responsive visual design, preparing sample movie catalog content, creating SVG poster illustrations, and drafting project documentation.

## Files and features affected

- `src/App.jsx`, `src/main.jsx`, `src/components/`, and `src/pages/`: application structure, navigation, components, hooks, forms, and page content.
- `src/data/movies.js`: fictional sample records and client-side data helpers.
- `src/styles.css`, `public/posters/`, `public/favicon.svg`, and `index.html`: styling, graphics, and page metadata.
- `README.md`, `render.yaml`, and `submission-links.txt`: documentation and deployment/submission preparation.

## Student responsibility

The group is responsible for inspecting, testing, understanding, maintaining, and explaining all submitted materials. Students should edit this declaration to accurately reflect any additional assistance or changes made during their own development. No credentials or private keys were supplied.

This declaration is maintained separately from the public-facing website because the project brief specifically requires disclosure of significant AI-assisted development work.
